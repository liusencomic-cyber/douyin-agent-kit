# 知识/方法论类内容的深度分析

适用于自我认知、个人成长、学习方法论、心理学等非工具类内容。

## 触发条件

当内容属于以下类型时，必须在标准流程的 Step 4（归纳总结）之后、归档之前，执行深度分析：

- 自我认知/个人成长方法论
- 心理学/行为学相关内容
- 学习/思维方法
- 任何声称"原创方法论"的内容

## 深度分析流程

### 1. 拆解底层逻辑

不要只做表面总结。识别方法论的核心结构：

- 输入 → 处理 → 输出 是什么？
- 每一步的假设是什么？
- 这个方法论的"独特性"在哪里（和常见做法有何不同）？

### 2. 映射现有理论体系

搜索已知理论/书籍/研究来对应：

| 理论体系 | 适用场景 | 典型书籍 |
|---------|---------|---------|
| Alfred Adler 个体心理学 | 自卑→补偿→追求优越 | 《自卑与超越》 |
| Ikigai（生き甲斐） | 热爱×擅长×世界需要×能赚钱的交集 | — |
| Gallup CliftonStrengths | 天赋主题识别 | 《现在，发现你的优势》 |
| Carl Jung 阴影理论 | 缺点中蕴含天赋 | — |
| Csikszentmihalyi 心流理论 | "浪费时间的事"=心流信号 | 《心流》 |
| Ken Robinson 天赋理论 | 天赋=天资×热爱×态度×机会 | 《让天赋自由》 |
| David Epstein 跨域学习 | 广泛涉猎→触类旁通 | 《跨能致胜》 |
| Anders Ericsson 刻意练习 | 天赋需要刻意练习转化 | 《刻意练习》 |
| Daniel Kahneman 系统1/系统2 | 直觉vs分析 | 《思考，快与慢》 |

### 3. 判断理论来源

- **重新发现**：博主从个人经验推导出与现有理论一致的结构 → 说明框架经过实践验证，价值高
- **直接引用**：博主明确引用某理论 → 检查是否准确转述
- **混合创新**：多个理论的通俗化组合 → 指出各部分的来源

### 4. 输出格式

在聊天中展示完标准总结后，追加：

```
## 🔍 理论溯源分析

**核心对应：** [最匹配的理论名称]
**关联度：** 高/中/低

**结构拆解：**
- [步骤1] → 对应 [理论A] 的 [概念]
- [步骤2] → 对应 [理论B] 的 [概念]
- [步骤3] → 对应 [理论C] 的 [概念]

**判断：** [重新发现/直接引用/混合创新]

**推荐阅读：**
- 《书名》— 作者（关联原因）
- 《书名》— 作者（关联原因）
```

### 5. 归档时补充

如果归档到 Obsidian，在笔记末尾追加一个"理论溯源"章节，包含上述分析。如果已有相关笔记（同一主题系列），更新现有笔记而非新建。

## 注意事项

- 不要强行套理论。如果方法论没有对应的成熟理论，诚实说明"未找到直接对应理论"
- 理论映射的目的是帮 用户 判断方法论的可靠性和深度，不是炫技
- 推荐书籍要有具体关联说明，不要只列书单
- 如果博主明确提到某本书/理论，优先检查其准确性
